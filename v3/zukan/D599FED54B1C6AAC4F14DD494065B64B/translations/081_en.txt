　　　　Selection of Whaling Grounds (Ryōba no Mitate)

If one intends to establish a whaling organization (kujira-gumi), the first priority must be to select a favorable location. When one successfully secures an advantageous location, whales can be caught in great numbers with little labor, and profits will naturally be abundant. When one fails to secure an advantageous location, expenses are wasted in vain, few whales are caught, and profits are naturally meager. Therefore, in establishing a whaling organization, the selection of the site is of the utmost importance. As for how to select a site: first and foremost, one should choose a location where whales frequently pass, and identify a place to set the nets.
(Interlinear note: Since the right whale [semі-kujira] swims close to the water's surface, there is no particular need to select a special location for setting nets — one may set nets wherever the whale is found. Since the humpback whale [zatō-kujira] dives deep toward the sea floor and travels along the bottom, one should select a location shallow enough that the height of the nets can reach, and prepare to set the nets there.)

## 大日本帝王系譜図

以下は、日本の歴代天皇の系譜を示した図である。

| 代数 | 天皇名 | 読み | 在位年数 |
|------|--------|------|----------|
| 第一代 | 神武天皇 | じんむ | 七十九年 |
| 第二代 | 綏靖天皇 | すいせい | 三十三年 |
| 第三代 | 安寧天皇 | あんねい | 三十八年 |
| 第四代 | 懿德天皇 | いとく | 三十五年 |
| 第五代 | 孝昭天皇 | こうしょう | 八十三年 |
| 第六代 | 孝安天皇 | こうあん | 百二年 |
| 第七代 | 孝靈天皇 | こうれい | 七十六年 |
| 第八代 | 孝元天皇 | こうげん | 五十七年 |
| 第九代 | 開化天皇 | かいか | 六十年 |
| 第十代 | 崇神天皇 | すじん | 六十八年 |
| 第十一代 | 垂仁天皇 | すいにん | 九十年 |
| 第十二代 | 景行天皇 | けいこう | 六十年 |
| 第十三代 | 成務天皇 | せいむ | 六十一年 |
| 第十四代 | 仲哀天皇 | ちゅうあい | 九年 |
| 第十五代 | 神功皇后（仲哀天皇の后） | じんぐう | 六十九年 |
| 第十六代 | 應神天皇 | おうじん | 四十三年 |
| 第十七代 | 仁德天皇 | にんとく | 八十七年 |
| 第十八代 | 履中天皇 | りちゅう | 六年 |
| 第十九代 | 反正天皇 | はんぜい | 六年 |
| 第二十代 | 允恭天皇 | いんぎょう | 四十二年 |
| 第二十一代 | 安康天皇 | あんこう | 三年 |
| 第二十二代 | 雄略天皇 | ゆうりゃく | 二十三年 |
| 第二十三代 | 清寧天皇 | せいねい | 五年 |

また、系譜中に日本武尊（やまとたけるのみこと）が第十四代仲哀天皇の父として記されており、第十五代神功皇后は仲哀天皇の后として明記されている。系譜の流れは第二十三代清寧天皇の後に続く。
